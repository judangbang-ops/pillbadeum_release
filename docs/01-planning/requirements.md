## 1. 읽는 법

- **ID**: `REQ-001`부터. 번호는 다시 쓰지 않음. 빼는 요구는 지우지 않고 상태를 '제외'로 바꾸고 날짜를 적음
- **문장**: EARS 다섯 꼴 중 하나로 씀. 항상(…해야 함) / …하면(사건) / …인 동안(상태) / …이면(원치 않는 경우) / …를 켠 경우(선택 기능)
- **우선**: Must = 1차 출시에 꼭 있음, Should = 1차에 넣되 막히면 미룰 수 있음, Could = 여유가 있으면
- **합격 기준**: `RR-1`~`RR-25`는 [기록 규칙 9장](https://github.com/judangbang-ops/DidITake/blob/7a800ac/docs/02-design/record-rules.md#9-반례별-기대-동작)의 반례, `RR-26`~`RR-67`은 [기록 규칙 보충](../04-spec/record-rules-supplement.md)의 반례이고, 그 표의 기대 동작이 곧 합격 기준임. 그 밖에는 "전제 → 동작 → 결과"로 씀
- **출처**: '기획 v3 3.1'은 planning-v3 3.1절, 'QA n'은 2026-11-11 QA 보고서의 확인 항목 n번, '결정 Qn'은 0장, '4장 n번'·'화면 5장 n번'은 2026-11-12 범위 확정 항목, '검토 An·Bn'은 [설계 독립 검토](../06-review/design-review-2026-11-11.md)의 항목, '보충 X-n'은 [기록 규칙 보충](../04-spec/record-rules-supplement.md)의 규칙, '킥오프 hh:mm'은 2026-11-11 킥오프 대화(저장소 밖 기록), 'Play'는 6장의 공식 문서, 'Claude 제안'은 Claude가 정한 것임
- **지금 코드**: 이 저장소 main(2026-11-12 `843a737`, DidITake `7a800ac` 프로토타입에서 패키지 이름만 바뀜)을 Claude가 읽고 판단함. 빌드·테스트는 CI 결과만 봤고 기기에서 실행하지 않음. 있음 / 일부 / 없음 / 다름 / 확인 전

## 6. 확인한 공식 문서 (2026-11-11)

- [Android 14 정확 알람 기본 거부](https://developer.android.com/about/versions/14/changes/schedule-exact-alarms): Android 13 이상을 대상으로 새로 설치한 앱은 `SCHEDULE_EXACT_ALARM`이 기본 거부됨. 백업 복원으로 옮겨도 거부 상태임. 대안은 `setAndAllowWhileIdle()`·`setWindow()`(최소 창 10분) 같은 비정확 알람
- [Play 민감 권한 정책](https://support.google.com/googleplay/android-developer/answer/16558241): `USE_EXACT_ALARM`은 알람·타이머 앱과 캘린더 앱에만 해당하고, 그 밖은 사용자가 허용하는 `SCHEDULE_EXACT_ALARM`을 쓰라고 함. 정책 원문 문장은 읽지 못했고 페이지 요약으로 확인함
- [Play 앱 서명](https://support.google.com/googleplay/android-developer/answer/9842756): 새 앱은 기본으로 Google이 만든 키로 서명되고, 첫 출시 전에 직접 관리하는 키로 바꿀 수 있음. 업로드 키는 앱 서명 키와 따로 둠. 이미 다른 키로 설치된 APK의 업데이트는 이 문서에 없음
- [Play 데이터 보안](https://support.google.com/googleplay/android-developer/answer/10787469): 데이터를 수집하지 않는 앱도 양식을 내야 하고, 양식에는 개인정보처리방침이 필요함. 기기 안에서만 처리하는 데이터는 '수집'이 아님
- [Play 건강 콘텐츠](https://support.google.com/googleplay/android-developer/answer/16679511): 건강·의료 앱은 건강 앱 신고를 내야 하고, 의료기기가 아님을 앱 설명에 적고 의료인과 상의하라고 알려야 함. 개인정보처리방침 링크를 Play Console에 넣어야 함

법적 판단은 하지 않음. Play 문서는 바뀔 수 있어 비공개 테스트 직전에 다시 확인함.
