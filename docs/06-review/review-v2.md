## 총평

문제 정의(이중투약 방지 = 멱등 기록)와 "앱은 기록 도구이며 의학적 판정을 하지 않음"이라는 선이 명확함. 반례 목록까지 있어 설계 입력으로 좋음. 다만 v2에서 확장 범위가 커지면서 키·시간·버전 규칙끼리 부딪히는 곳이 5군데 생김.

## 구조 충돌 5개와 해결

[planning-v3 5장](../01-planning/planning-v3.md#5-확정된-결정-v2-열린-질문-2026-11-11)으로 확정함.

| 취소의 의미 | 무효 처리 (이력 보존) | 확장(처방·투약 이력)에 이력이 필요함 |
| 주 1회의 "주" | 기준 요일 창 하나 + 늦은 투약 시 기준일 이동 설정 | 달력 주는 조기 투약 유도(T7a), 롤링 7일은 요일이 밀림(T7d) |
| 자정 직후 기록 | 하루 시작 시각 설정, 기본 04:00 + 마지막 기록 표시 | 00:00 경계는 23:59/00:01이 갈림(T6a), 경계는 옮겨질 뿐 사라지지 않음(T6c) |
| 가족 약 위젯 | 위젯 1종 + 위젯마다 대상자 필터 | 위젯 종류를 늘리지 않고 배치로 해결함 |

## 그 밖의 지적 (v3 반영)

- 진료일(Visit) 엔티티가 없어 "지난 진료일 ~ 오늘" 요약의 기준점이 없었음
- 주사 부위는 일기가 아니라 투약 기록의 속성임
- 일기는 무슨 날의 일인지와 쓴 시각을 분리해야 함. 같은 분 메모 정렬 기준이 필요함
- 미복용 계산 범위(일정 시작 전·중단 구간·보관 항목 제외)와 복용률 분해가 필요함
- 6.2는 늦은 투약만 다루고 조기 투약을 다루지 않았음
- 하드 삭제 + 외래 키면 갱신 안 된 위젯 버튼이 예외를 냄 → 보관 처리 (T4b)
- `INSERT OR IGNORE`의 0행 결과를 곧바로 "중복"으로 보면 안 됨 (T4a)
- Android 자동 백업이 기본으로 켜져 있어 "백업은 별도 검토"와 충돌함
- 위젯·알림·잠금 화면에 약 이름이 노출됨
- 서버가 없으므로 기기 두 대 사이의 이중투약은 막을 수 없음을 명시해야 함

## 실증 결과

실행: `python3 -I evidence.py` → `23/23 단언 성립`, 종료 코드 0 (SQLite 3.52.0, Python 3.14.2)

- [재현]: 기획 그대로면 문제가 실제로 생기는지 확인함 (PASS = 문제가 재현됨)
- [해법]: 제안한 해법이 그 문제를 막는지 확인함 (PASS = 막힘)

| T | 구분 | 확인 내용 |
| --- | --- | --- |
| T1a | 재현 | 이벤트 로그 + `UNIQUE(약, 기간)`: 취소 이벤트 자체가 안 들어감 |
| T1b | 재현 | `UNIQUE(약, 기간, 유형)`으로 바꿔도 취소 후 재기록이 막힘 |
| T2 | 해법 | `active` NULL 구조: 연타 무시, 취소 후 재기록, 이력 3행, 활성 1행 |
| T3 | 참고 | SQLite 부분 유니크 인덱스도 같은 효과 (Room `@Index`로는 선언 불가) |
| T4a | 재현 | `OR IGNORE`는 NOT NULL 위반도 조용히 넘김 → "이미 기록됨"과 신호가 같음 |
| T4b | 재현 | 외래 키 위반은 `OR IGNORE`로도 예외 → 삭제된 항목의 위젯 버튼 탭이 예외 |
| T5a / T5b | 재현 / 해법 | 체크 후 삽입이 엇갈리면 유니크 없이 2건, 유니크 있으면 1건 |
| T6a / T6b / T6c | 재현 / 해법 / 재현 | 경계 00:00이면 23:59·00:01이 다른 날, 04:00이면 같은 날, 03:59·04:01은 여전히 갈림 |
| T7a / T7b | 재현 / 해법 | 달력 주는 금요일 약이 월요일부터 미완료, 기준 요일 창은 완료 유지 |
| T7c | 재현 | 월요일 약을 일요일 밤에 맞으면 다음 날 아침 새 창이 미완료 (간격 10시간) |
| T7d | 재현 | 롤링 7일은 한 번 늦으면 요일이 영구히 밀림 |
| T8 | 재현 | 달력 연도 + ISO 주번호 키가 2026-12-31 / 2027-01-01에 갈라짐 |
| T9a / T9b | 재현 / 해법 | 주기 바꾼 당일 키만 보면 2회 통과, 창 판정이면 막힘 |
| T10a / T10b | 재현 / 해법 | 갱신 안 된 위젯 탭이 거짓 기록, 렌더 기간키 대조로 새로고침 |
| T11a / T11b | 재현 / 해법 | 상대 회차 키가 기준일 이동 뒤 충돌, 날짜 키는 충돌 없음 |
| T12 | 해법 | 건너뜀 칸의 위젯 탭은 무시, 앱에서 바꾸면 이력을 남기고 복용으로 |

한계: Room·Glance·실기기(갤럭시 절전 포함) 동작은 이 실증 범위 밖임. 구현 단계에서 확인함.
