6. **기기 간 이전** (RR-29, Smart Switch). 에뮬레이터는 `bmgr`의 기기 간 이전 표시(`is_device_transfer=true`)로 흉내만 냄. 런처가 위젯을 되살리는 것(`onRestored`)은 보지 못함
7. **실기기 Android 16의 WorkManager 2.7.1**. 에뮬레이터 API 36으로 대신함

## 6. 관찰 (판정 아님)

- 화면 확인 2부 API 34·36: 위젯의 항목 여섯 개를 차례로 누를 때 앞의 다섯 번은 보이는 칸이 그대로였고, 마지막 Weekly를 누른 뒤에는 다 보이는 칸이 넷에서 둘로 줄었음. 캡처를 보면 Weekly 칸이 '마지막 복용 11/15(일) 08:31' 석 줄에서 '일 08:39 먹음' 두 줄로 낮아져, 같은 스크롤 위치에서 첫 줄이 반쯤 가려짐. 목록이 맨 위로 돌아가지는 않음(REQ-078의 스크롤과 다름 없음). 이 관찰 줄은 2026-11-14부터 스크립트가 남겼지만 문서에 옮긴 적은 없었음
- 알림 확인 API 26·30: 알림 밀어서 지우기를 System UI가 받지 않아 '모두 지우기'로 대신 지움(스크립트의 한계, 앱에는 같은 삭제 인텐트가 감). API 36은 두 번째 밀기에 지워짐
- 앱 시험 `AccessScreenTest.the_first_screen_says_nothing_while_no_item_has_reminders_on`이 PR #55의 첫 CI([44998677714](https://github.com/judangbang-ops/pillbadeum_release/actions/runs/44998677714), `8805d82`)에서 한 번 실패함: `performMeasureAndLayout called during measure layout`(`AccessScreenTest.kt:268`). 같은 시험이 다음 CI(45002503236)에서 통과. 그 사이 바꾼 것은 다른 시험 파일뿐임. 원인은 아직 보지 않았고, 다시 실패하면 원인을 찾음
