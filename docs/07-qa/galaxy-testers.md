# 갤럭시 확인: 가족·지인 테스터 안내

시험용 갤럭시가 없어서, 갤럭시를 쓰는 가족·지인 세 분이 자기 폰에 개인 APK를 깔고 해 보는 방법입니다. 갤럭시를 PC에 USB로 꽂을 수 있을 때의 방법은 [갤럭시 확인 순서](device-check.md)(adb, `scripts/device/device-check.ps1`)이고, 이 문서는 그 순서를 사람이 손으로 할 수 있는 만큼 줄인 것입니다.

- **정함**: 2026-11-16 18:06 KST 동희님이 프로젝트 채팅에서 "나 갤럭시 없는데 어떻게 하지?", 18:15 KST 같은 채팅에서 다 완성되면 가쟈누님과 동희님 주변 두 분께 "apk로 해보라할거야". 그래서 테스터는 그 세 분이고, 누구에게 무엇을 부탁할지는 동희님이 정합니다
- **APK**: 앱 서명 키로 서명한 개인 APK `pillbadeum-0.1.0-274-personal.apk`(`scripts/sign-personal-apk.ps1`, main `92c5cb6`, versionCode 274, 파일 SHA-256 `45D52A93647E1C3A94830C3CF3D333E3771C45D328EA2B7CBDA947F5F9709AD9`). 만든 곳과 확인한 것은 [진행 기록](../10-records/progress.md) 2026-11-16 '갤럭시 없이: 지인 테스트'에 있습니다
  - 보내는 법: 카톡으로 파일을 보내거나, 카톡이 APK를 받지 않으면 Google Drive의 사본을 링크로 공유합니다(공유 범위는 동희님이 정함). 폴더째 공유하지 않고 APK 파일 하나만 공유합니다. 그 폴더에는 다른 앱의 파일도 있습니다. 같은 Drive 폴더의 `-tempkey.apk`는 보내지 않습니다. 서명이 달라 그것을 먼저 깐 폰에는 개인 APK와 뒤의 빌드가 덮어 깔리지 않습니다
  - 고른 까닭(Claude): 고친 빌드와 나중의 Play 버전을 지우지 않고 덮어 깔 수 있어 테스터의 기록이 이어집니다(REQ-062). CI 임시 키 APK는 빌드마다 키가 달라 새 빌드를 줄 때마다 지우고 다시 깔아야 하고, 그때 기록이 지워집니다
  - [WBS 3장](../08-wbs/wbs.md#3-순서) '결정이나 승인이 먼저 필요한 작업'의 'TASK-047의 가족 폰' 줄은 Claude 제안이 TASK-050(앱 서명 키를 Play에 넘김) 뒤였고, 더 일찍 깔면 적어도 TASK-002의 키 확인과 TASK-051을 마친 뒤로 적었습니다. 둘 다 끝나 있습니다(TASK-002: RSA 4096 확인, TASK-051: 끝남)
  - 남는 위험(검토 A1): TASK-050에서 키를 Play에 넘기지 못하면, 이 APK를 깐 폰은 Play 버전으로 바꿀 때 앱을 지우고 다시 깔아야 하고 그 폰의 기록이 지워집니다
- **결과가 오는 길**: 테스터가 캡처와 메모를 동희님께 카톡으로 보냄 → 동희님이 Claude 스레드에 올림 → Claude가 `docs/07-qa/<첫 결과 날짜>-galaxy/report.md`에 정리([양식](device-check-template.md)을 이 방법에 맞게 고쳐 씀)
- **설치 제한 확인**: Google의 개발자 인증 요건은 2026-09-30부터 브라질·인도네시아·싱가포르·태국의 참여 스토어에만 걸리고, 직접 받은 APK(사이드로드)에는 아직 걸리지 않으며 전 세계 확대는 2027년입니다([개발자 인증](https://developer.android.com/developer-verification), [FAQ](https://developer.android.com/developer-verification/guides/faq), 2026-11-16 Claude가 조사 에이전트로 읽음). 그래서 지금 한국 갤럭시에는 '출처를 알 수 없는 앱' 허용만으로 깔립니다. 2027년 확대 뒤 APK로 나눠 줄 때는 다시 확인합니다
- **지키는 것**: 캡처가 오가므로 진짜 약 이름 대신 보여도 괜찮은 이름을 씁니다. 다른 앱 알림, 연락처 같은 개인 정보가 찍히면 가려서 보냅니다. 폰 PIN은 묻지도 적지도 않습니다. 테스터의 원본 캡처는 저장소에 올리지 않고, 보고서에는 고른 캡처와 숫자만 옮깁니다

## 2. 테스터에게 보낼 글

카톡에 그대로 붙여 넣을 수 있게 썼습니다. 메뉴 이름은 One UI 판마다 조금 다를 수 있어 '찾아 주세요'로 적은 곳이 있습니다.

### 2.1 모두에게

```text
[필받음 갤럭시 테스트 부탁해요]
필받음은 먹은 약을 홈 화면 위젯으로 한 번에 적는 앱이에요. 기록은 폰 안에만 있고 인터넷을 안 써요.
캡처를 보내 주셔야 해서 약 이름은 '비타민'처럼 보여도 괜찮은 이름으로 써 주세요. 다른 앱 알림이나 개인 정보가 찍히면 가려서 보내 주세요.
(캡처: 전원 버튼 + 볼륨 아래 버튼을 같이 짧게)

1) 깔기
- 보낸 apk 파일을 눌러 받고 [열기]
- '출처를 알 수 없는 앱'이 뜨면 [설정] → '이 출처 허용' 켜고 뒤로 → [설치]
- '자동 차단' 때문에 막히면: 설정 > 보안 및 개인정보 보호 > 자동 차단을 잠깐 끄고 설치한 뒤 다시 켜기
- Play 프로텍트 경고가 뜨면 '세부정보 더보기' → '무시하고 설치' (문구는 폰마다 조금 달라요)
- 설정 > 휴대전화 정보 화면과 그 안의 '소프트웨어 정보' 화면을 캡처해 주세요

2) 처음 위젯 (제일 중요해요)
- 앱을 처음 열면 나오는 안내에서 [다음] → [위젯 추가] → 뜨는 창에서 [추가]
  (창이 안 뜨면 그대로 알려 주세요)
- 홈 화면에 생긴 위젯이 10초 안에 글자를 보여 주는지 봐 주세요. '불러오는 중'이나 빈 칸만 계속 보이면 문제예요 → 위젯 캡처
- 앱에서 [시작하기] → [항목 추가]로 약 2개 만들기
- 위젯에 2개가 보이면 캡처. 위젯에서 하나를 눌러 체크 표시로 바뀌기까지 바로인지 몇 초인지 알려 주세요

3) 일주일 써 보기
- 먹을 때마다 위젯이나 알림의 [먹었어]로 기록해 주세요. 앱은 안 열고 위젯만 쓰는 날도 있으면 좋아요
- 항목을 눌러 [알림 받기]를 켜고 시각을 정하면 그때 알림이 와요. 알림이나 '정확한 알람' 허용을 물으면 허용해 주세요
- 알림이 늦게 오면 정한 시각과 실제로 온 시각(알림에 적힌 시각)을 알려 주세요. 특히 밤새 안 만진 다음 날 아침 알림이요
- 아침에 위젯 날짜가 오늘로 바뀌었는지 봐 주세요 (하루는 새벽 4시에 바뀌어요)
- '앱이 멈췄어요' 창이 뜨거나 이상하고 헷갈리는 곳은 언제든 캡처해서 보내 주세요

새 버전을 보내면 지우지 말고 그냥 덮어 깔면 돼요. 앱을 지우면 기록도 지워져요.
```

### 2.2 한 분께 더 (20분)

화면 잠금(PIN 등)이 있는 폰이어야 합니다.

```text
[잠금 화면 테스트 (15분)]
약 이름이 잠금 화면에 안 보이는지 보는 거예요.
1. 새 항목 2개(테스트A, 테스트B)를 만들고, 둘 다 [알림 받기]를 켜고 첫 알림 시각을 지금부터 3분 뒤로 저장 → 화면 끄고 기다리기
   ('정확한 알람' 허용 안내가 뜨면 [허용하기]. 안 켜면 알림이 10분쯤 늦을 수 있어요)
2. 알림이 오면 잠금은 풀지 말고 화면만 켜서 캡처① → 알림을 아래로 끌어 펼쳐서 캡처②
   (약 이름 없이 '복용 시간이에요'만 보여야 정상)
3. 잠금을 풀고, 휴대폰 설정에서 '잠금화면 알림'을 찾아 '내용 숨기기' 켜기 → 화면 껐다 켜서 캡처③
4. 필받음 > 설정 > [잠금 화면에 약 이름 보이기] 켜기 → 화면 껐다 켜서 캡처④ (이름이 안 보여야 정상)
5. 휴대폰 설정의 '내용 숨기기' 끄기 → 화면 껐다 켜서 캡처⑤ (이번엔 약 이름과 [먹었어]가 보여야 정상)
6. 잠금을 풀지 말고 테스트A의 [먹었어] 누르기 → 캡처⑥ → 잠금 풀고 앱에서 테스트A가 먹음으로 바뀌었는지 캡처⑦
7. 끝나면 [잠금 화면에 약 이름 보이기]를 다시 끄고, 테스트A·B는 항목을 눌러 [보관]

[큰 글씨 위젯 (3분)]
1. 설정 > 디스플레이 > 글자 크기와 스타일에서 글자 크기를 가장 크게
2. 홈 화면 빈 곳을 길게 눌러 위젯 > 필받음 → 하나 더 놓기
3. 캡처 (약 이름이 잘리거나 낱말 중간에서 끊기는지)
4. 글자 크기를 되돌리고 새로 놓은 위젯은 지워도 돼요

[다시 시작 (2분)]
폰을 다시 시작하고 잠금을 푼 뒤 위젯이 오늘 날짜로 보이는지 캡처
```

### 2.3 해 주실 수 있으면: 위젯 누르는 화면 녹화

REQ-070(위젯 반영 시간)의 P50·P95를 재려고 합니다. 빠른 설정 패널의 '화면 녹화'를 켜고, 위젯의 약을 하나씩 눌러 바뀌는 것을 몇 번 찍어 녹화 파일을 보내 주시면, Claude가 프레임으로 누른 때와 바뀐 때를 잽니다. 같은 약을 한 번 더 누르면 '이미 기록됨'이 떠서 그것도 잴 수 있습니다.

## 3. 받은 결과 정리 (Claude)

- 사람마다 기기(모델, One UI, Android 판), 깔면서 막힌 곳, 1장의 확인별 결과를 적습니다. 숫자는 테스터가 보낸 시각과 캡처에서 옮기고, 사람이 말로 전한 것은 그렇게 적습니다
- 끝나면 요구 문서(REQ-048·REQ-070 줄), [시험 계획](../12-qa/test-plan.md)(TC-013, BUG-004), [WBS](../08-wbs/wbs.md)(TASK-032·052·054·047)의 상태를 고치고, 1장의 '못 보는 것'은 남은 것으로 둡니다
- 이름 표시가 끔인데 잠금 화면에 이름이 한 번이라도 보이면 TASK-025의 방법을 고칩니다(TASK-052 끝난 조건)
- 잠금을 푼 알림창에 '<이름> 먹어~!'와 따로 '복용 시간이에요'가 보이는 것은 정상입니다. 이름을 숨기는 기본 설정에서 잠금 화면용으로 따로 띄우는 알림(SPEC-013)이고, 남은 약 알림을 다 처리하면 같이 사라집니다. 2026-11-17 [시연 영상](../10-records/progress.md)에서도 보였습니다. 테스터가 '알림이 두 개'라고 하면 문제로 적지 않습니다
