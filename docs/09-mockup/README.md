# 09 목업: 방향 두 가지 (1차 릴리즈)

상태: CORTHEX 09 다시 하기 초안 (2026-11-12, Claude). 방향 고르기 확인 전.

목업 캔버스: [필받음 1차 목업 방향](https://claude.ai/artifact/QW5JRsx1Zpz5ekeqHmjpKC) (claude.ai 아티팩트, 동희님 계정 전용). 보드 6개.

## 0. 다시 그린 까닭

첫 초안(17:20)은 이전 웹 제품의 Pillbox 디자인 시스템 토큰으로 위젯 칸형·줄형과 첫 화면 카드형·목록형을 그렸음. 동희님 말씀 (2026-11-12 17:34 KST, 이 스레드): "목업 너무 안예쁜데;;;; 왤캐 AI 슬롭이 심하냐;; 이거 해결좀해봐".

Claude가 짚은 원인:

- 회색 바탕, 흰 카드, 초록 버튼만 되풀이함. '건강 앱'이라는 이름만 듣고도 누구나 고를 색임
- 대상자를 색 점이 달린 알약 모양 태그로 나타냄
- 가짜 상태 표시줄을 넣음
- ⋯·＋·▾를 그림 대신 글자 기호로 넣음
- 기본 글꼴을 씀
- 모든 항목이 같은 카드임

그래서 배치만 다른 두 후보를 버리고, 약을 먹는 실제 물건에서 출발해 서로 다른 방향 두 개를 다시 그림.

## 1. 장면과 재료

장면: 챙기는 사람이 아침에 부엌이나 식탁 앞에서 약을 손에 든 채 홈 화면을 힐끗 보고 '먹었나?'를 1초 안에 확인하고, 한 번 눌러 남김. 밝은 곳이라 밝은 화면.

재료: 약국 약봉투(흰 종이, 아침·점심·저녁 칸, 이름), 도장과 인주, 요일별 약통(7칸, 칸마다 색 뚜껑), PTP 은박 포장, 냉장고 달력의 볼펜 체크, 처방전 표, 출석부.

같은 데이터를 씀 (11/12 (목), 하루 시작 04:00, 한국 시간):

| 나 | 아침약 | 매일 | 복용 08:02 | `오늘 08:02 먹음` |

### 1안 약봉투: 종이에 잉크로 찍은 기록표

| 부분 | 값 |
| --- | --- |
| 색 | 종이 #F6F2EA, 잉크 #1D2740, 보조 글자 #5A6072, 가는 선 #DCD4C4, 도장 주홍 #B3391F (먹은 기록에만) |
| 글꼴 | IBM Plex Sans KR, 숫자는 같은 폭 (tabular-nums) |
| 상태 | 먹음 = 시각이 든 주홍 원 도장(−9° 기울임), 아직 = 점선 네모, 건너뜀 = 빗금 네모·회색 '건너뜀' 도장 |
| 대상자 | 색 대신 이름 글자. 첫 화면은 대상자별로 묶고 묶음 제목을 둠 |
| 위젯 | 항목마다 한 줄(48dp 이상), 1.5dp 잉크 선 아래 목록 |
| 첫 화면 | 날짜 머리(26sp), 이번 주 7칸 네모, [먹었어]는 잉크로 채운 버튼, [기록 취소]는 밑줄 글자 버튼 |

### 2안 요일 약통: 사람마다 뚜껑 색이 있는 칸

| 부분 | 값 |
| --- | --- |
| 색 | 흰 바탕, 글자 #15171C, 나 파랑 #2B59C3 (옅은 면 #E4ECFB), 엄마 주황 #C2501A (옅은 면 #FBE7DC), 건너뜀 회색 #ECEDEF |
| 글꼴 | Gothic A1 |
| 상태 | 먹음 = 그 사람 색으로 꽉 찬 칸과 흰 체크, 아직 = 옅은 칸과 점선 동그라미, 건너뜀 = 회색 칸 |
| 대상자 | 칸 색과 이름 글자를 함께 |
| 위젯 | 한 줄에 두 칸. 글자 200%면 한 줄에 한 칸 |
| 첫 화면 | 요일 배지, '오늘' 두 칸씩, '이번 주 약통' 7칸 격자, [먹었어]는 그 사람 색 버튼 |

## 3. 잰 것 (2026-11-12 17:45 KST, Claude)

이 컨테이너의 Chromium에서 보드를 그려 CORTHEX `page-check.js`로 잼. 실제 글꼴(Google Fonts)을 씀. 안드로이드 기기에서 본 것은 아님.

| 보드 | 대비 | 옆으로 잘림 | 위젯에 보이는 항목 |
| --- | --- | --- | --- |
| 1안 위젯 100% | 통과 | 없음 | 3개 (넷째는 스크롤) |
| 1안 위젯 200% | 통과 | 없음 | 1개 남짓 |
| 1안 첫 화면 | 통과 | 없음 | |
| 2안 위젯 100% | 통과 | 없음 | 4개 모두 |
| 2안 위젯 200% | 통과 | 없음 | 1개 반 |
| 2안 첫 화면 | 통과 | 없음 | |

- 세로로 잘린 글자는 위젯 목록 아래쪽, 곧 스크롤로 보는 부분뿐임.
- 대비를 맞추느라 빠짐 칸 테두리와 지나지 않은 요일 글자를 처음 값보다 진하게 고침. 테두리는 3:1, 글자는 4.5:1을 넘김.
- 글자 200%는 안드로이드 14 이상의 비선형 확대를 따라 14sp를 약 26dp, 16sp를 약 28dp로 그림.

## 4. 위젯 공통 (R2 기술 시험 TASK-042에서 온 사실)

- '더 있음'은 가려진 동안만 보일 수 없음. 위젯은 스크롤 위치를 앱에 알려 주지 않음. 그래서 넘칠 때 늘 보이는 작은 아래 화살표로 그림. 글자로 쓸지와 그 문구는 동희님이 정함.
- 칸은 줄 단위 목록(LazyColumn)으로 만듦. 격자로 만들면 탭할 때마다 맨 위로 돌아감.
- 최소 크기 250×110dp에서는 머리글 아래 목록이 55dp라 한 줄 남짓만 들어가고, 글자 200%면 39dp라 한 줄도 다 안 들어감. 최소 높이를 올릴지, 머리글을 줄일지 정해야 함 (REQ-026).

## 5. 확인할 것 (09 확인)

1. 방향: 2안 요일 약통 (추천) / 1안 약봉투 / 둘 다 아님

추천 이유: 엄마 약까지 챙기는 앱이라 누구 약인지가 색으로 바로 보이고, 위젯 100%에서 4개가 다 보임. 반론: 대상자가 많아지면 색을 다시 써야 하고, 1안보다 화면이 시끄러움.

## 6. 확인 뒤에 할 것

- 고른 방향으로 나머지 화면(SCR-002, 003, 005~010)을 같은 캔버스에 그림.
- `design/base.tokens.json`(DTCG)을 고른 방향의 값으로 만듦. 이전 Pillbox 아티팩트는 고치지 않음.
- 글꼴을 앱에 넣을지 정함. 넣지 않으면 기기 기본 한글 글꼴로 보임.
- 고른 배치와 다른 화면 정의가 있으면 08 `docs/05-ui/screens.md`를 고침.
