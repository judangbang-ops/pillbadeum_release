# 09 목업: 방향 두 가지 (1차 릴리즈)

상태: CORTHEX 09 다시 하기 초안 (2026-11-12, Claude). 방향 고르기 확인 전.

목업 캔버스: [필받음 1차 목업 방향](https://claude.ai/artifact/QW5JRsx1Zpz5ekeqHmjpKC) (claude.ai 아티팩트, 동희님 계정 전용). 보드 6개.

## 1. 무엇을 그렸나

두 후보 모두 같은 데이터와 같은 색·글자·모서리를 씀. 색은 이미 있는 [필받음 Pillbox 디자인 시스템](https://claude.ai/artifact/TptV94SiBghXnviinrP3o5)(판 1792643140-7f83)의 토큰을 그대로 가져옴. 다른 것은 배치뿐임.

같은 데이터 (11/12 (목), 하루 시작 04:00, 한국 시간):

| 대상자 | 항목 | 주기 | 오늘 상태 | 보조 문구 |
| --- | --- | --- | --- | --- |
| 나 | 아침약 | 매일 | 복용 08:02 | `08:02` |
| 엄마 | 혈압약 | 매일 | 미완료 | `마지막 복용 어제 21:40` |
| 나 | 비타민D | 매일 | 건너뜀 09:10 | `건너뜀` |
| 엄마 | 골다공증약 | 주 1회 (월) | 미완료 | `마지막 복용 11/02(월) 08:10` (S-2 날짜 글자, 이름과 같은 크기, REQ-075) |

| 보드 | 화면 | 후보 | 크기 |
| --- | --- | --- | --- |
| A 칸형 위젯 · 글자 100% | SCR-001 | A: 한 줄에 4칸 (지금 시안과 같은 배치) | 350×213dp |
| A 칸형 위젯 · 글자 200% | SCR-001 | A | 350×213dp |
| B 줄형 위젯 · 글자 100% | SCR-001 | B: 항목마다 한 줄, 목록만 스크롤, `더 있음` | 350×213dp |
| B 줄형 위젯 · 글자 200% | SCR-001 | B | 350×213dp |
| A 카드형 첫 화면 | SCR-004 | A: 항목마다 카드, [먹었어]·[기록 취소]·[⋯] 글자 버튼 | 360×800dp |
| B 목록형 첫 화면 | SCR-004 | B: 대상자별 묶음 줄, 동그라미를 눌러 기록 | 360×800dp |

- 위젯 크기 350×213dp는 Pixel 런처의 4×2 실제 크기(TASK-042 기술 시험)임. 명세의 최소 크기 250×110dp(SCR-001 규칙)는 더 좁으므로, 고른 방향을 그 크기에서도 다시 봐야 함.
- 글자 200%는 안드로이드 14 이상의 비선형 글자 확대를 따라 14sp를 약 26dp로 그림. 아이콘·동그라미는 dp라 커지지 않음.
- 글꼴: 안드로이드 기본 한글 글꼴 대신 Noto Sans KR로 그림. Pillbox의 Pretendard는 앱에 넣지 않으면 쓰이지 않음.

## 2. 보이는 차이

| | A | B |
| --- | --- | --- |
| 위젯 100% | 4개가 한눈에 보임. 칸 폭이 약 72dp라 보조 문구가 서너 줄로 꺾이고, 다섯 글자 이름 `골다공증약`은 이미 잘림. 대상자는 색 점으로만 보임 (Pillbox의 '색은 이름과 함께' 규칙과 어긋남) | 3개가 다 보이고 4번째는 반쯤 보인 채 목록 안 스크롤 + `더 있음`. 대상자 이름이 글자로 보임. 가로로 잘리는 글자 없음 |
| 위젯 200% | 4칸은 그대로지만 머리글과 네 항목의 이름이 모두 잘림 → REQ-066(가장 큰 글자에서 잘리지 않음)을 못 지킴 | 머리글이 두 줄이 되고 한 번에 한 개 반이 보임. 가로로 잘리는 글자 없음 → REQ-066을 지킴, 대신 스크롤이 늘어남 |
| 첫 화면 | 명세 그대로 글자 버튼. 누르기 분명하지만 한 화면에 3개쯤만 보임. 미완료 카드마다 초록 채운 버튼이라 Pillbox의 '주 버튼은 한 화면에 하나' 규칙과 어긋남 | 위젯과 같은 몸짓(동그라미 누르기)으로 기록, 먹음을 다시 누르면 기록 취소를 물음. 한 화면에 더 많이 보이지만 글자 버튼이 없어 처음엔 덜 분명함. 고르면 SCR-004의 버튼 정의를 고침 |

위젯 두 줄의 잘림은 Claude가 이 컨테이너의 Chromium에서 보드를 그려 글자 상자가 버튼 밖으로 나가는지 잰 결과임(2026-11-12 17:25 KST). 글꼴은 컨테이너의 대체 한글 글꼴이라 실제 휴대폰과 몇 dp 다를 수 있음. 실제 위젯 확인은 고른 방향을 구현한 뒤 에뮬레이터 둘러보기로 함.

추천(Claude): 위젯은 B(REQ-066 때문에), 첫 화면은 A(명세를 바꾸지 않고, 처음 쓰는 사람에게 분명함). 섞으면 위젯과 앱의 몸짓이 다르다는 반론이 있음: 위젯은 동그라미, 앱은 글자 버튼.

## 3. 확인할 것 (09 확인)

1. 위젯: A 칸형 / B 줄형
2. 첫 화면: A 카드형 / B 목록형
3. 색: 지금 앱 시안의 파랑(#1D4E89) 대신 Pillbox 초록(#0B6B4F)과 사람 색(파랑 #2F66C2, 주황 #DB7A1F, 보라 #5B3A9E)으로 바꿀지

## 4. 확인 뒤에 할 것

- 고른 방향으로 나머지 화면(SCR-002, 003, 005~010)을 같은 캔버스에 그림.
- `design/base.tokens.json`(DTCG)을 Pillbox `tokens.json`에서 앱이 쓰는 것만 옮겨 만듦. Pillbox는 목록 형식이라 바꿔 적어야 함. Pillbox 아티팩트 자체는 고치지 않음.
- 고른 배치와 다른 정의가 있으면 08 `docs/05-ui/screens.md`를 고침 (B 목록형이면 SCR-004 버튼).
