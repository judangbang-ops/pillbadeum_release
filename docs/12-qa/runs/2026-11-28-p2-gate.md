# 2차 친구 대상 APK 릴리스 게이트 (항목 248)

판정: 보류. 기준 `d4eadab`은 TASK-068의 `09484a4` 이후 문서만 바뀌었다. 실기기와 전체 게이트 시험의 유효한 증거가 부족하며 사용자님의 출시 결정은 아직 없다.

- TASK-068 원본은 서버 작업공간 `task-068-release-qa`의 커밋되지 않은 보고서와 증거다. 시험 계획 31줄을 이 브랜치에 가져왔다. 원본 보고서와 273MB 원본 증거는 해당 작업공간에 남아 있으며 아직 Git에 보존되지 않았다.
- 당시 TC-090~120은 27건 통과, 3건 일부, 1건 미확인이다. 일부 확인 TC-096·105·112는 통과로 간주하지 않는다. TC-110의 공개 방침은 2026-11-27 친구 대상 APK 결정으로 해당 없음이나, 기존 승인된 REQ-109와 TASK-067의 기록은 이 결정과 대조해 별도 정리해야 한다. 기존 시험 계획은 과거 결과를 보존한다.
- 1차 297에서 2차 440으로 같은 시험 키를 사용한 API 36 덮어 설치에서 대상자·기록·위젯과 2→3 이주를 확인했다. 실제 배포 인증서로 297→2차를 설치한 시험은 아니다. 서명 파이프라인은 고정 인증서 지문을 확인한다.
- One UI 위젯 및 긴급 정보, TalkBack 발화, 실기기 백업·복원, 강제하지 않은 플랫폼 동작은 미확인이다. 기존 시험 계획은 다섯 상태 및 gate 열이 없어 전체 차단 건 수를 신뢰성 있게 산출할 수 없다. 사용자 면제 0건을 확인한 것이 아니라 면제 기록을 아직 조사하지 못했다.
- CI 45412701870은 `09484a4` 성공이고 `d4eadab` 자체의 실행이 아니다. 공개 PR은 조사 당시 0건이다. GitHub 환경에 서명 비밀값 이름 2개와 main 브랜치 정책이 존재하지만 비밀값의 유효성은 배포 전 검증되지 않았다.
- main 병합 시 앱 경로 변경으로 빌드와 에뮬레이터 확인 후 조건이 맞으면 GitHub 릴리스 APK를 생성하며 Obtainium 사용자에게 노출된다. 최종 버전은 병합 커밋의 도달 가능한 커밋 수로 정해지므로 지금 확정할 수 없다. 기준 브랜치 `d4eadab`의 수는 443이고 이전 297보다 크다.
- 스키마 3 설치 후 복구는 데이터 삭제나 1차 앱 재설치가 아니라 스키마 3을 여는 수정 APK로 한다(WBS 3.1). 실기기와 백업 확인 후 1대에서 성공 신호와 기한을 정해 확인하고 확대하는 것을 추천한다. 자동 배포가 전체 테스터에 노출되는 현재 구조에서는 별도 카나리 통제가 확인되지 않았다.
